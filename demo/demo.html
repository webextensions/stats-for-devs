Tap targets

Mobile input

Focus this field on a phone to watch the virtual-keyboard and viewport metrics react.

Device orientation

Enable the Device orientation metrics and tilt / rotate the phone (the Tilt indicator visual aid draws a bubble level from the same data). Browsers only deliver sensor events over HTTPS (or localhost) - over plain LAN HTTP the rows say needs https; use the hosted demo above or an HTTPS tunnel. On iOS the rows say tap to enable - tap any of them to trigger the permission prompt. On a desktop they simply report no data.

Performance

Enable the Performance metrics (and try setting a threshold on them, so they turn red). JS heap is Chromium-only.
